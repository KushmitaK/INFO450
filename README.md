## 📌 Course & Project Overview
This repository contains coursework, data pipelines, and analytical models developed for **INFO 450: Programming for Business Analytics**. The project focuses on applying Python to solve real-world business problems by transforming raw data into actionable, data-driven insights and predictive models.

### Core Focus Areas
- **Data Wrangling:** Cleaning, restructuring, and processing large, complex datasets.
- **Exploratory Data Analysis (EDA):** Generating summary statistics and interactive data visualizations.
- **Statistical & Predictive Modeling:** Building regression, classification, and forecasting models to drive business decision-making.
